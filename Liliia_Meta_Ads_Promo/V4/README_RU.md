# Liliia Meta Ads Promo — предварительная V4

Точечная правка V3: видимые просветы между тремя строками «Помогу привлечь клиентов для вашего бизнеса» одинаковые — 24px. Расстановка учитывает фактическую высоту букв каждой строки, а не только размер шрифта.

На End Card имя уменьшено86→44px, вес750→600, цвет светло-серый. Специализация36px, второстепенный блок. Главный белый акцент — «Напишите «РЕКЛАМА» в Direct»:67/74px, вес800/750. Призыв перенесён ближе к центру; Instagram60px остаётся заметным. Фон графитовый, без цветных элементов.

Хук, основные кадры, рабочие планы, тексты, музыка, продолжительность и плавность появления/затухания сохранены. 18,03сек, 1080×1920,30fps, H.264/AAC. V3 и оригинальный MOV не изменены. Это предварительный экспорт, не утверждённая финальная версия.

Музыка: Realizer — Kevin MacLeod, CC BY4.0, та же дорожка V2/V3 без перекодирования. Лицензия допускает коммерческое использование при атрибуции: добавьте music/CREDITS.txt в описание объявления. Документы лицензии и мастер сохранены в music.

Редактирование: project/design.json — надписи, тайминги, equal_ink_gap; end-card/component.json — отдельный финальный экран. SVG/PNG/MP4 расположены в end-card. Для пересборки нужны Python3.12+, Pillow, FFmpeg/ffprobe. Запустите python project/render.py; проверка — python project/validate.py. Все исходники и шрифт с лицензией включены.
