# Liliia Meta Ads Promo — предварительная версия V1

18,03 секунды · 1080×1920 · 30 fps · MP4 H.264 / AAC.

Исходный монтаж сохранён: 451 кадр в исходной последовательности, без ускорений и цветокоррекции. В конце — плавный переход к фирменному экрану. Оригинальный MOV не изменён.

Редактирование:
- `project/design.json` — тексты, тайминги, шрифт, розовый цвет, музыка.
- `end-card/component.json` — отдельный редактируемый End Card.
- `end-card/End_Card.svg` — векторный экран для редактирования в дизайнерских программах; шрифт Montserrat вложен в assets.
- `end-card/End_Card.png` — полноразмерный статичный экран.
- `end-card/Liliia_Meta_Ads_End_Card.mp4` — самостоятельная анимированная версия экрана.

Для пересборки: Python 3, Pillow, NumPy и FFmpeg. Установите зависимости из requirements.txt и запустите `python project/render.py`. Проверка: `python project/validate.py`.

Музыка: Realizer — Kevin MacLeod, CC BY 4.0. Разрешено коммерческое использование с указанием авторства, включая монтаж в рекламном видео. Точный текст атрибуции находится в `music/CREDITS.txt`: добавьте его в описание рекламного объявления при публикации. Музыкальный мастер, сведения об источнике, лицензия и подтверждение прав сохранены в music. Звук исходного MOV заменён лицензированной музыкой.

Это предварительная версия для согласования. Финальный рекламный экспорт не выполнялся.
