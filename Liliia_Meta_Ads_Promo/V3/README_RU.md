# Liliia Meta Ads Promo — предварительная V3

18,03сек · 1080×1920 · 30fps · MP4 H.264/AAC.

Точечная доработка V2. Хук, текстовый сценарий, порядок основных сцен, музыкальная дорожка и общая длительность сохранены. Исходный MOV и V2 не изменены; контрольные суммы проверены.

## Изменения

0–3,067сек: три хука V2 без изменения текста и размеров. «Больше»52px; «КЛИЕНТОВ»104px/700, «ПРОДАЖ»112px/750, «ПРИБЫЛИ»120px/800. Последний акцент самый сильный.

3,067–7,2сек: исходные кадры Ads Manager сохранены. Текст перенесён на y650 — ниже самой светлой области экрана. Мягкая тень и локальное затемнение с плавным краем улучшают читаемость. Плашек и рамок нет.

7,2–8,4сек: крупный план работы на ноутбуке из оригинальных кадров7,2–8,4сек; акцент «Анализ.».
8,4–11,067сек: реальные записи в блокноте из оригинальных кадров8,4–10,4сек, с деликатным замедлением0,75x и кадрированием, которое следует за рукой. Акценты «Стратегия.» и «Целевые заявки.» остаются в ритме V2. Пустой интерьер больше не занимает основную площадь этих планов. Это новые ракурсы из существующего MOV; новые сцены не генерировались. Более тесное кадрирование немного уменьшает запас детализации по сравнению с общими планами.

11,067–14,867сек: прежние кадры с Лилией. «Помогу привлечь клиентов для вашего бизнеса» сохранено в трёх строках, размер уменьшен70→66px, блок поднят1160→1080px, ниже лица.

14,867–18,033сек: графитовый End Card, без цветных акцентов и градиентов. Имя86px без изменения; специализация37→44px; Instagram54→60px; CTA усилен весом800 и строкой «в Direct»74px. Появление0,3сек, полная читаемость2,57сек, затухание0,3сек. Фон сохраняется до конца без чёрного кадра.

Realizer — Kevin MacLeod, CC BY4.0. Та же лицензированная дорожка, что в V2, перенесена без повторного кодирования; включая музыкальную синхронизацию и финальное затухание. Совпадение аудиопакетов проверяется валидатором. Лицензия разрешает коммерческую адаптацию и использование в платной рекламе с атрибуцией. Текст для описания рекламного объявления: music/CREDITS.txt. Авторская страница, метаданные мастера, полный музыкальный файл и официальный текст лицензии сохранены в music.

## Редактирование и сборка

project/design.json — надписи, расположение, тайминги, параметры рабочих фрагментов, музыка и переход к финалу.
end-card/component.json — отдельный редактируемый End Card; SVG/PNG и анимированный MP4 находятся рядом.
project/build_picture.py — последовательная сборка рабочих фрагментов; кэш обновляется при изменении параметров picture_edit.
project/build_assets.py — генерация текста и End Card с Montserrat, лицензия OFL вложена.

Нужны Python3.12+, Pillow и FFmpeg/ffprobe. Установите requirements.txt. Для сборки: `python project/render.py`. Для проверки: `python project/validate.py`. Проект содержит оригинальный MOV, все активы, музыку и лицензии. Оригиналы не перезаписываются.

Это предварительная версия для согласования. Финальный рекламный экспорт не выполнялся.
